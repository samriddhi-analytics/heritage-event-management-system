# Heritage Event Management System

## Project Overview
The Heritage Event Management System is a Python-based application designed to organise heritage-related events and manage visitor records. It demonstrates application development, database operations, and the use of SQL for structured data management.

## Features
- View and manage heritage event records.
- Record visitor details through the application.
- Store and manage information using a database.
- Use SQL scripts for database setup and operations.
- Access project documentation and the project report.

## Technologies Used
- **Programming Language:** Python
- **Database:** SQLite
- **Query Language:** SQL

## Project Files
- `app.py` — application entry point.
- `heritage_events.db` — SQLite database.
- `heritage_event_management.sql` — SQL script.
- `Project_Report.pdf` — project report.
- `README.txt` — original project instructions.

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Review `README.txt` for the original setup instructions.
4. Open a terminal in the project folder.
5. Run:

   `python app.py`

6. Follow the instructions displayed by the application.

## Learning Outcomes
This project demonstrates practical experience with Python application development, database integration, SQL, and structured record management.
